# `safe_a` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `hint.safe_a`, an anchor that links only to an `http`/`https` address with a host, rendering a rebuilt
`href` and degrading to a `span` otherwise.

**Architecture:** A plain function in `hint/_helper.py` built from `hint._core.element`, re-exported flat from the
`hint` boundary. No new types.

**Tech Stack:** Python 3.14, `urllib.parse.urlsplit`/`urlunsplit`, pytest + hypothesis, pyright strict, ruff `ALL`.

**Spec:** `docs/superpowers/specs/2026-11-27-safe-a-design.md`

## Global Constraints

- Calling convention: `safe_a([children], {attrs})` — both positional, both required, no keyword args or defaults.
- `_helper.py` imports `hint._core`, never the package boundary (so not `hint.a` / `hint.span`).
- Allowed schemes are exactly `http` and `https`, with a non-empty netloc. Nothing else, relative included.
- The rendered `href` is always `urlunsplit(urlsplit(href))`, never the stored string.
- Refusal never raises; it returns a `span` with the same children and attrs minus `href`.
- `make check` green before every push. Commits: conventional, scope `tags`.

## Review Focus

- A value `urlsplit` itself rejects, e.g. `"http://[::1"` (raises `ValueError`) — must refuse to a `span`, not crash the
  page.
- An empty or whitespace-only `href` — refused, `span`.
- An allowed address containing `"` or `<` in the path — stays a link; `render` escapes the value.
- A non-ASCII host, e.g. `"https://bücher.example/"` — allowed, rebuilt unchanged.
- Leading whitespace on an otherwise good address, `" https://x.org"` — allowed, rendered without the space.

Attribute _names_ are code, not stored data, so an `HREF` key is out of scope (the threat is the value).

- [ ] **Step 1: Write the failing tests** in `src/hint/safe_a_test.py`, importing only from `hint`, asserting on
      `render(...)` output:

```python
@pytest.mark.parametrize("address", [
    "javascript:alert(1)", "JaVaScRiPt:alert(1)", "\x01javascript:alert(1)",
    "java\tscript:alert(1)", "data:text/html,x", "ftp://example.com/",
    "https:example.com", "/relative/path", "//example.com/", "", "   ", "http://[::1",
])
def test_refuses_a_non_web_address(address: str) -> None:
    assert render(safe_a(["x"], {"href": address, "class": "c"})) == '<span class="c">x</span>'

def test_refuses_a_missing_href() -> None:
    assert render(safe_a(["x"], {"class": "c"})) == '<span class="c">x</span>'

@pytest.mark.parametrize(("address", "rendered"), [
    ("https://example.com/a?b=1#c", "https://example.com/a?b=1#c"),
    ("http://example.com/", "http://example.com/"),
    ("HTTPS://Example.com/a", "https://Example.com/a"),
    ("ht\ttps://example.com/", "https://example.com/"),
    (" https://x.org", "https://x.org"),
    ("https://bücher.example/", "https://bücher.example/"),
])
def test_links_a_web_address_by_its_rebuilt_form(address: str, rendered: str) -> None:
    assert render(safe_a(["x"], {"href": address})) == f'<a href="{rendered}">x</a>'

def test_escapes_an_allowed_address() -> None:
    assert render(safe_a(["x"], {"href": 'https://x.org/"><b>'})) == '<a href="https://x.org/&quot;&gt;&lt;b&gt;">x</a>'
```

attribute starts with `http://` or `https://`.
